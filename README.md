# Kuri Village · Kalinchowk — ride itinerary

A static website for Sarthak & Rahul's 4-day motorbike trip from Kathmandu, on a Yamaha MT-15 and a Hero XPulse 200 4V. It has two plans to choose from:

- **Kalinchowk**: Kathmandu → Kuri Village → Kalinchowk Bhagwati (3,842 m) → Dolakha → Jiri → Kathmandu
- **Mustang**: Kathmandu → Tatopani → Kali Gandaki → Muktinath (3,710 m) → Pokhara → Kathmandu

The home page always asks which itinerary to open. You can switch between them from the header at any time.

## What's inside

- Full-screen sections for the hero, riders, an interactive route map, the elevation profile, each day, the budget, prep and the finale
- A Leaflet map using only free, keyless tiles: OpenStreetMap (a softened "Light" style and standard "Street") and OpenTopoMap ("Terrain"). It draws real road geometry for each day, with a dashed line for the summit walk. No API keys are needed anywhere.
- An elevation profile with hover and drag readouts, plus a table view
- A packing checklist saved on your device, and live weather for Kuri or Muktinath from Open-Meteo

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
```

`npm run build` writes a fully static site to `out/`, which you can host anywhere (Vercel, Netlify, GitHub Pages, S3…).

## Data

- `data/trips.ts`: all itinerary content (days, stats, tips, budget, checklist)
- `data/routes/*.json`: road geometry, stop distances and elevation samples, generated by `npm run route:build` (OSRM + Open-Meteo)
- `public/images/web`, `public/images/mustang`: Wikimedia Commons photos. Authors and licences are in each folder's `credits.json` and are listed on the site.
- `public/images/ours`: our own reference photos of Kuri

Distances are measured along real roads. Ride times come from the itinerary. Elevations come from a 90 m terrain model, so peaks read slightly low.
